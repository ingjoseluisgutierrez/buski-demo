
# 🔎 Buski – Tu Comparador de Precios Inteligente

Buski es una app prototipo construida con [Streamlit](https://streamlit.io) que permite visualizar en un solo lugar las mejores ofertas de productos disponibles en tiendas online como **Mercado Libre**, **Alkosto** y **Éxito**.

## 🚀 ¿Qué hace esta app?

- Muestra productos extraídos automáticamente desde tiendas reales.
- Filtra resultados por tienda o palabra clave.
- Permite descargar los datos en formato CSV.

## 🧰 Tecnologías utilizadas

- Python
- Streamlit
- SQLite
- Web Scraping + API

## 📦 Archivos clave

- `app.py` → Código principal de la app Streamlit.
- `offers.db` → Base de datos con productos y precios recolectados.

## ▶️ ¿Cómo correrla en Streamlit Cloud?

1. Haz fork o sube este repositorio a tu cuenta de GitHub.
2. Ve a [https://streamlit.io/cloud](https://streamlit.io/cloud) y haz login.
3. Crea una nueva app, selecciona el archivo `app.py`.
4. ¡Listo! Tu comparador estará en línea 🚀

## ✨ Vista previa

Puedes personalizar el diseño, filtros y lógica de recolección de datos para expandir la funcionalidad según tus necesidades.
